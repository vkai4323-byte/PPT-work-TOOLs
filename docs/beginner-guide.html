先明白一件事

比直接让 Codex 做 PPT，多了什么？

原来的 Codex 也能制作 PPT。这套工作台增加的是一套可重复使用的做事方法和检查工具。

01 / 修改更有范围

说改哪儿，就围绕哪儿改

把“改一句”“整页重排”“全稿统一”分清楚。已有 PPT 修改后，还会检查有没有动到其他页或误改文案。

02 / 接得住你的手改

你在 WPS 改过，也能继续

把保存好的最新版交回来，它先保留一份，再在副本里修改，避免拿旧稿重新生成、盖掉你的成果。

03 / 多轮工作能接续

换个聊天，不必从头解释

项目文件里留有版本、已确认内容和待办。新聊天可以先读这些记录，再接着做；相关文件要一起保留。

它不会保证每次都比原来更漂亮。它更擅长让制作和修改有依据、能检查、可接续；创意方向与最终效果仍由你判断。

复制给 Codex

$ppt-workbench 根据我提供的文案和客户资料，先做黑底白字的 PPT 初稿。先理顺每页要讲什么，图片留占位。参考我给的版式；不要擅自删掉关键机制。不明确的事实单独列出来。

Agent（就是替你操作的 Codex）会这样做
  1. 读资料，区分客户要求、创意内容和版式参考。
  2. 安排页序和信息层级，制作文字稿并预留图的位置。
  3. 检查一些文字溢出、重叠等排版问题，再输出可编辑 PPT。
你收到：一份可编辑 PPT，以及需要你确认的问题。

你重点看：逻辑是否顺、重点是否明确、关键内容有没有漏。

一个很有用的小习惯

每次说清三件事：哪里、怎么改、保留什么

这样的要求，方向还不够明确

“这页不行，再高级一点。”
它可能需要进一步确认，你想改的是文字、版式还是图片。

这样说，更容易改到你想要的样子

“第 8 页整页重排：三位达人并排，每人一列。头像小一点，作品图大一点。姓名、报价和已确认文案都保留。”

不用描述坐标、字号参数或操作命令。说清你想让读者先看到什么，以及哪些内容不能动，就很有帮助。

第一次使用 · 交给 Codex 安装

你只需要复制，然后跟着提示做

这套安装包面向 Windows 电脑。第一次需要联网下载一些组件；等待时可以让 Codex 告诉你卡在哪一步。

  1. 1. 把右边整段话发给 Codex

    让它下载、安装并检查，而不是只告诉你一串操作命令。

  2. 2. 按提示退出，再打开 Codex

    安装完成后开一个新聊天，让新增能力生效。

  3. 3. 给资料，说你现在要做什么

    在开头加上 $ppt-workbench，明确使用这套工作台。这串字发在聊天里就行。

几件容易误会的事

装上以后，它会自动变得更聪明吗？

不会更换模型，也不是给 AI 换一个“大脑”。它增加了制作规则、文件处理和检查工具。结果仍与模型、资料和要求是否清楚有关。

以后每次新项目都能用吗？

完成安装并重启后，通常可以在新项目、新聊天中使用。开头写 $ppt-workbench 最明确。若它说工具不可用，让它检查安装状态，不用从头描述全部原理。

能自己找图、生成图、放进 PPT 吗？

可以让 Agent 按项目需要完成这些工作，但搜图、生成图片、读取某些平台需要电脑上有对应工具和权限。工作台本身负责记录图片用途和放置计划，并不附送所有生图或搜索服务。已有素材可以直接提供。

我在 WPS 改了，Codex 会马上知道吗？

不会。先保存文件，再把最新版交给它，说“以这份为准”。它会从这份继续修改。不要只说“我改过了”，却仍让它读取旧文件。

右侧预览没变化，是不是没有改成功？

有可能仍显示旧版。先打开 Agent 刚交付的新文件，再核对变化和批注。当前不保证同一路径被覆盖后，右侧画面会自动更新。

是不是再也不会出现“图片过多”报错？

不能保证。工作台减少不必要的重复截图，但不能清除聊天里已有的图片。若当前聊天因此卡住，可保留项目文件，开新聊天让它读取项目记录继续。

检查通过，就可以直接交客户了吗？

仍要看一遍。工具能发现一些排版和误改问题，但不能替你确认客户事实、创意是否成立、头像是否对应正确、图片是否合适。涉及版式和配图时，也要让 Agent 查看实际效果。

交付后，哪些文件应该留下？

对外通常发最新 PPTX 就够了。自己要保留整个项目文件夹和相关素材，便于后续修改、回退和换聊天接续。不要只留下聊天截图。换电脑时，让 Agent 帮你检查文件是否带齐。

最重要的一句：
“以这份最新版为准，先保留，再修改。”你可以从任何一步开始，也可以随时退回去调整内容。
