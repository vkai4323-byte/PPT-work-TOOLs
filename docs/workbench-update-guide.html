      你可能也想问

      先把几个小问号解开。

      每次做 PPT，都要重新安装吗？

      不需要每次重装。首次完整安装并验证后，日常在 Codex 里说需求即可。新电脑需要重新安装；已有电脑更新时，Codex 会检查版本和配置。

      我已经在 PowerPoint 改过了，还能继续吗？

      可以。先保存最新文件，再交给 Codex，说明改哪几页、哪些内容保留。它应以这份文件为准，另存修改版本；复杂效果仍要打开实际文件检查。

      生成图是不是能当成达人以前的作品？

      不能。真实过往作品来自对应账号，新的生成图用于表达本次创意。两者分开记录和展示，也不代表达人已经合作或发布过这条内容。

      我想只留一块截图，怎么说？

      直接说“只保留这条作品的发布展示块，不要侧栏，保留标题和封面”。Codex 会先留原图，再裁出副本并看图检查。无需你填写坐标。

      下载 Workbench，会附送生图额度吗？

      不会。工作台组织和调用流程，生图使用客户已有且获授权的服务。本轮计划生成多少张、如何计费、是否允许重做，都先与你确认。

      今天做一半，明天能接着来吗？

      可以保存项目和进度继续。换聊天时，把整个项目文件夹的位置告诉 Codex；只带走一个导出的 PPTX，不能恢复全部素材与制作过程。
