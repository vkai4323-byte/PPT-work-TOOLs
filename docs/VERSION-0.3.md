# 0.3.0：新建与原生精修双管线

新建/持续改 HTML deck 使用已有测量与导出能力；用户在 WPS/PowerPoint 手改后，正式接管最新版 PPTX，在副本中继续修改。原稿、历史版本与工作稿分开保存，不逆向同步 HTML。

| 新工具 | 作用 |
|---|---|
| pptx_inspect | 按真实页序读取 slide ID、目标页对象、文案、几何与图片关系；默认页序摘要 |
| pptx_adopt / pptx_resume | 接管已保存 PPTX、保留版本、记录当前依据、跨会话接续 |
| pptx_prepare | 创建副本；元素/整页/多页/全稿范围；默认保护文案 |
| pptx_batch | 调用本机 OfficeCLI 原子 JSON 批处理；先备份、核对哈希；不安装 CLI |
| pptx_review / pptx_commit | 检查范围、文案、对象和共享资源变化；保存新版本 |
| ppt_asset / ppt_placement_plan | 素材指纹与用途、来源、放置框、图文组合、裁切和保留项记录 |

每个检查均返回文字，不默认把图片送入模型。原生差异检查不是完整 schema 或视觉认证；结构与视觉验收需真实执行后记录。独立版本文件改善旧预览缓存问题，不代表同路径自动刷新已实现。

OfficeCLI 为外部依赖，安装 workbench 不会自动下载安装它。已有 OfficeCLI 可直接调用；未安装时核对官方安装方式和本机环境，或使用已可用、适合当前原生对象的编辑工具。图像生成、达人检索和官方素材获取不随本包自动获得。

素材计划保存路径与指纹，不内置生图或智能自动布图；跨电脑需带齐项目与素材，核对新路径。选中标题可以用于定位整页批注，不要求另一套前端编辑器。通用 PPTX→HTML 对象映射、双向同步、模型图片历史裁剪均未实现。

升级：下载新版后运行 install.ps1，沿用自定义安装参数。0.3.0 使用独立版本目录，保留旧运行时与配置备份；重启 Codex/新开聊天加载25个工具。当前会话未加载 MCP 时可用技能的 CLI 入口。

具体操作见 [使用指南](USAGE.md) 与 [原生精修规则](../skills/ppt-workbench/references/native-pptx-workflow.md)。

## 设计规则补充（2026-10-27）

两条路线共用的 [设计与改稿规则](../skills/ppt-workbench/references/design-workflow.md) 已补齐：逐页视觉重点、按阅读用途选择的字号层级、主辅区域比例、色块分区、网格与留白、整组版式节奏，以及六项视觉检查。数值均为可覆盖的起点；用户要求、强制模板及已确认设计优先。仅做文字/颜色小改时不扩大为整页重设计。

本次更新为 Skill 与文档改进，工具数量和引擎不变；不新增自动审美评分，也不宣称已经实测证明成品更漂亮。已安装的电脑需获取最新版并重新运行安装器更新 Skill，再在新聊天使用。
