# 0.3.1：达人取材与布图接续

本次针对中途接入工作台、批量获取达人作品封面和多轮补图场景。仍为 25 个工具，兼容旧项目；旧计划没有完整图位清单时，不推算完成率。

- 新增达人取材技能参考：先验证一个完整样本；原封面导出、可见截图、可用替代路径按能力选择；记录失败避免无变化重试；无法取得时保留受阻图位，不伪造真实作品。
- 布图计划支持 slots：未取材需求也计入总数，区分身份、真实作品、本次创意封面、场景图。记录取材尝试、受阻原因和语义匹配判断。
- 区分已取材、已布图、已展示、用户确认/否决。后续状态绑定版本，版本或素材变化后旧状态列为 stale。展示和反馈仍由调用方如实记录，程序不能证明用户真的看过或认可。
- pptx_commit 支持 contextPatch，与新版本原子写入当前状态，减少“文件已改、待办仍未改”的接续错位。resume 返回 lastRevision，帮助识别未同步记录的提交。
- 不包含新的社交平台采集服务，不接管浏览器登录，不会强制取消其他工具的阻塞调用；也不自动插图、不自动判断创意匹配、不清理模型图片历史。

升级：重新运行本版 install.ps1，保留原有自定义参数，然后 verify.ps1。新版运行时安装到 0.3.1 子目录，旧版目录保留。完全退出再打开 Codex，以加载更新的工具参数和技能；其他电脑也需升级。
