# 0.2.0：更可靠的多轮提案制作

## 本次新增

1. **灵活工作规则**：内容梳理、黑底白字文字稿、补图、美术升级可以按项目组合。区分内容依据、版式参考、美术参考和强制模板，用户本轮要求优先。
2. **源项目快照**：修改工具自动保存清单、页面、素材和笔记；同内容素材去重。直接文件编辑前主动 snapshot。恢复默认预览，携带当前指纹执行，提前验证快照，自动保存恢复前版本；写入失败尝试回滚。
3. **稳定元素定位**：为主要对象添加 data-ppt-id，通过元素当前指纹定点编辑，防止陈旧修改与误改同文案对象。页面内插入、移动兄弟对象不改变 ID。
4. **项目与素材记录**：保存当前重点、需求、参考用途、已确认项、待办及素材查阅摘要。查阅记录按内容指纹验证，文件替换会失效，相同内容换名可复用记录。
5. **跨聊天接续**：deck_resume 汇总状态、笔记、快照和导出是否匹配当前源文件，返回文字。没有重建模型隐藏上下文。

## 如何升级

获取仓库当前版本或 downloads/PPT-Workbench-Codex-0.2.0.zip，退出正在使用旧运行时的 Codex，运行 install.ps1。新版安装在版本目录 0.2.0，重新注册同名 MCP 和 Skill，原配置备份、旧运行时保留。重启 Codex，再执行环境检查。自定义配置目录时沿用 -InstallRoot、-UserHome、-CodexProfile。

0.1.0 源项目可直接使用，不需要重建。需要精准定位的页面再调用 deck_identify；旧导出缺少新指纹时被标记为未验证，检查并重新导出即可。旧项目此前没有保存的完整快照无法补回。

## 可以直接这样说

```text
$ppt-workbench 这次先套客户模板并补关键示意图，文案后面再改。
记录模板的固定要求，不要把流程锁定为先黑白稿再补图。
```

```text
$ppt-workbench 修改前保存一轮快照。只改第 3 页玩法卡片 B 的说明，其他页保持当前内容。
```

```text
$ppt-workbench 列出补图前的版本，恢复到那版源项目，再检查并导出。
```

```text
$ppt-workbench 继续这个项目，先读取当前决定、参考资料用途和待办。
已有素材按指纹核对，需要判断构图的页面仍做实际视觉检查。
```

## 边界

- 快照不是宿主自动每轮监控。绕过工具写文件前必须主动保存；不备份任意外部文件、导出目录或模型聊天历史。
- 常规写入异常会尝试回滚；断电或强制结束进程仍可能需要从安全快照恢复，不能等同数据库事务。
- 本版恢复整个受管理源项目，选择性保留某页需要在恢复前另存，再重新应用与检查。
- 素材查阅记录由调用方声明，不代表工具看过图片或模型仍能看到它，更不等于视觉验收通过。
- 不提供右侧编辑器或与官方 Artifact Session 的双向同步。官方 Presentations 在支持该环境时已有实时画布，未来应评估复用。
- 不增加出图账号、达人检索服务、任意 PPTX 无损导入，也不清理 Codex 的图片历史。

验收情况见根目录验收说明.md；目标电脑自然语言自动路由和特定业务稿仍需实际使用确认。
